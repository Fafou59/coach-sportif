# Coach sportif IA

Coach d'entraînement d'endurance (course route et trail, vélo, renfo, mobilité) qui tourne gratuitement sur Claude Free, avec synchronisation Garmin. Il fixe les objectifs, construit un plan sur mesure et suit son exécution, à partir d'un référentiel de règles sourcé.
