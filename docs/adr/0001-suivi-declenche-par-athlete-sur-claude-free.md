# Suivi déclenché par l'athlète, faute de proactivité sur Claude Free

Le coach doit tourner gratuitement sur le forfait Claude Free, qui ne permet pas les tâches planifiées (vérifié le 14/11/2026 : réservées aux forfaits payants). Le suivi « quotidien » est donc un **check** lancé par l'athlète, qui reste silencieux s'il n'y a rien à signaler. Une alerte poussée par un script sur un serveur personnel (sans IA, à seuils) est envisagée en V2 si le rituel ne tient pas.

## Options écartées
- Forfait payant avec tâches planifiées : contraire à l'objectif de gratuité.
- Script d'alerte dès la V1 : chantier technique jugé prématuré.
