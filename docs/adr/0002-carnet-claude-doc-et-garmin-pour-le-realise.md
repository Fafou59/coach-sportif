# Le carnet est un Claude Doc ; Garmin fait foi pour le réalisé

En Free, Claude ne peut ni modifier les fichiers d'un projet ni rouvrir un artefact classique depuis une autre conversation, et sa mémoire automatique n'est pas pilotable. Un test sur compte Free (14/11/2026) a montré qu'un Claude Doc peut être rouvert et modifié depuis une nouvelle conversation à partir de son lien. Chaque athlète a donc un **carnet** sous forme de Claude Doc, tenu à jour par le coach, qui fait foi pour tout ce qui est décidé ; le calendrier et les activités Garmin font foi pour ce qui est planifié à court terme et réalisé.

## Options écartées
- Fichier du projet régénéré et réimporté à la main : corvée pour l'athlète, risque de version périmée.
- Artefact : pas de mise à jour documentée depuis une autre conversation en Free ; stockage persistant payant.
- Mémoire Claude seule : non contrôlable, résumée.
